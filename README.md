# 🏠 Home Loan Default Prediction

## 📌 Project Overview

This project focuses on predicting whether a loan applicant is likely to default on a home loan using Machine Learning techniques. The objective is to identify high-risk applicants and support better data-driven lending decisions.

The project integrates multiple financial datasets, including application details, credit bureau records, previous applications, POS cash balances, credit card balances, and installment payments, to build a comprehensive loan default prediction system.

## 🎯 Business Objective

The main goal is to identify potential loan defaulters at an early stage, helping financial institutions reduce credit risk, improve lending decisions, and minimize financial losses.

## 📂 Datasets

The project uses the following datasets and these are available in HomeLoanDef.docx file:

- `application_train.csv` – Applicant information and loan repayment target.
- `bureau.csv` – Previous credit information from other financial institutions.
- `bureau_balance.csv` – Monthly balances of previous credits.
- `POS_CASH_balance.csv` – Monthly POS and cash loan balance information.
- `credit_card_balance.csv` – Monthly credit card balance information.
- `previous_application.csv` – Previous loan application details.
- `installments_payments.csv` – Previous installment payment records.
